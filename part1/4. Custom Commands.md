# 나만의 슬래시 명령어 만들기
- 프로젝트 루트에 `.claude/commands/` 폴더를 만들고 `.md` 파일을 넣으면 `파일 이름 = 슬래시 명령어`가 된다.
- `claude.md`의 트리거 키워드와 비슷하지만 슬래시 명령어는 `탭 자동완성`이 되고 Claude Code가 **구조적으로 인식**하기 때문에 더 안정적
```
ex)
.claude/
    commands/
        review_script.md    →  /review_script
        deploy_staging.md   →  /deploy_staging
```
