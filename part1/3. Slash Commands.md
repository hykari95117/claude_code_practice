# 필수 슬래시 명령어
## 컨텍스트 관리 - /clear · /compact · /context
- **`/clear`** : 컨텍스트 초기화
    - **새 작업**을 시작할 때 반드시 사용
    - 쌓여있던 컨텍스트 토큰 모두 정리, 이전 대화가 쌓이면 200K 토큰 공간이 줄어들고 응답 품질도 떨어진다.
- **`/compact`** : 컨텍스트 압축
    - **대화 맥락은 유지**하면서 토큰만 줄여준다.
        - `/clear` = 완전 초기화
        - `/compact` = 맥락 유지하며 압축
- **`/context`** : 토큰 사용량 확인
    - bar 형태로 현재 사용량을 보여준다.
    - 80% 이상이면 `/clear` 혹은 `/compact` 사용

## 모델 & 세션 & MCP - /models · /resume · /mcp
- **`/model`** : 모델 전환
    - Opus : 가장 똑똑, 복잡한 아키텍처/어려운 버그
    - Sonnet : 균형잡힌 성능, 일반적인 코딩 작업
    - Haiku : 가장 빠름, 간단한 질문/파일 탐색
- **`/resume`** : 이선 세션 복구
    - 터미널을 실수로 닫았을 때 Claude Code 다시 실행 후 `/resume`으로 이전 대화 복원
- **`/mcp`** : MCP(외부 도구 연결) 관리
    - 현재 사용하고 있는 모든 MCP 서버를 보여준다.
    - 안 쓰는 MCP는 비활성화, 켜져있으면 토큰만 낭비(MCP 서버는 컨텍스트를 차지)

## 기타 유용 - /help · /config · /export · /output-style
- **`/help`** : 내장 도움말
- **`/config`** : 설정 변경(To-Do 리스트 활성화 등)
- **`/export`** : 채팅 내보내기(Cursor 등으로 옮길 때 유용)
- **`/output-style`** : 응답 스타일 설정(학습 모드, 간결 모드 등) → v2.1.91에서 제거
